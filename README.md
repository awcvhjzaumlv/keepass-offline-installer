## 📖 About KeePass

KeePass is a free, open-source password manager for Windows that stores passwords in a strongly encrypted local database. As the original open-source password manager, it has spawned numerous ports and compatible clients for all major platforms.

---

## ❌ Problem: KeePass is hard to access

- **Windows-Primary** — Native KeePass runs on Windows; other platforms use third-party ports
- **No Official Browser Extension** — Browser autofill requires third-party plugins with varying quality
- **Manual Sync** — Database sync across devices requires setting up Dropbox or similar manually
- **Dated Interface** — UI design significantly older than modern password managers
